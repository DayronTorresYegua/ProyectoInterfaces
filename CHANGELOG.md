# Changelog

## 18-10-2026 · Cierre de la Órbita 1

- La IA usada en esta parte del proyecto ha sido en relacion para las diferentes opciones de figma como pueden ser los componentes, conjntos de componentes, variables, etc...

- Se le pide a la IA como hacer que desaparezcan tareas al hacer click
- Responde que para hacerlo puedo hacer uso de variables y añadir interacciones de forma que al hacer click en una tarea esta se oculte
- Se conserva lo devuelto de forma que ahora funciona de forma interactiva
- Se cambio que antes las tareas eran estaticas

- Se le pide a la IA como hacer que muestre una cosa u otra dependiendo de si es verdadero o falso
- Devuelve que haciendo variables de componente se puede hacer de forma que si el valor es true o false muestre una cosa u otra
- Se conserva que ahora las paginas hacen uso de variables de componentes de forma que ahora muestran una cosa u otra dependiendo del valor que tenga
- Se cambio que antes para mostrar las dos variantes tenia que tener creadas dos paginas, ahora solo una que cambia.
